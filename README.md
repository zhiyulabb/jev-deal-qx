# Jev 双11购物通知（待真机验证）

1. **配置 Jev key，无需创建本地文件。** 在 https://console.typesafe.ai 获取 key。圈 X 配置现有 `[task_local]` 段下添加 `0 0 * * * https://raw.githubusercontent.com/zhiyulabb/jev-deal-qx/main/jev_deal.js#setup-key=YOUR_API_KEY, tag=Jev API配置, enabled=true`，仅在手机上把 `YOUR_API_KEY` 替换成真实 key。保存后在请求列表把任务向右滑动执行一次，看到“API key 已保存”后删除这条任务。URL的 `#` 片段不进入HTTP请求，但包含key的本地配置仍是敏感信息，不分享、不上传、不截图。公开脚本第一行保持 `apikey_xxx`。此前的本地 `jev_setup.js` 方式不再需要，删除含key的旧文件和快捷指令。仓库：https://github.com/zhiyulabb/jev-deal-qx 。
2. **引用规则并获取慢慢买配置。** 圈 X「重写 → 引用」填写 `https://raw.githubusercontent.com/zhiyulabb/jev-deal-qx/main/jev_deal.conf`，启用并更新资源。完成第3步后，打开慢慢买 App「我的」，出现“慢慢买配置已保存”通知即可；参数只保存在本机，不显示内容、不推送 GitHub、不发给 Jev，只用于向慢慢买查询。接入方法参考 [githubdulong 模块](https://raw.githubusercontent.com/githubdulong/Script/master/Surge/jd_price2.sgmodule)及 [wf021325 查询脚本](https://raw.githubusercontent.com/wf021325/qx/master/js/jd_price.js)，请求流程重新实现，未复制其 HTML 注入或 Env 运行库。京东通过商品 ID 查询商品映射、价格走势、价格摘要；V1映射请求失败或返回信息不完整时，先用V2解析链接取得stteId，再尝试V2商品映射，共最多5次历史请求（V1失败1次＋V2链路4次），不循环重试；匹配失败或接口失效回退近90天本地浏览记录。第三方历史缓存6小时，返回哪些价格就显示哪些：历史最低、30/60/180天最低、618、双11与日期。优惠条件未核实，不能把第三方价格当作已验证的同条件到手价。淘宝目前仅有本地记录。通知先显示 Jev，再显示当前价格、历史价格与来源；不是修改商品页面。Jev 只接收提取的商品字段、价格摘要和本地记录，不接收慢慢买配置、请求签名、Cookie 或原始响应。首次没有可比记录、价格条件缺失或动作置信度低于0.55时建议为“信息不足”。同标题同现价且商品身份与配置一致的成功分析不会再次请求或通知；配置变更允许重新分析。
3. **启用 MitM 并验证。** 启用 `api.m.jd.com`、`trade-acs.m.taobao.com`、`in.m.jd.com`、`apapia-sqk-weblogic.manmanbuy.com`，安装并信任圈 X 证书，分流不用改。商品 JSON 提取最多六层；有标题、有效价和商品 ID 才分析，淘宝还要求 SKU ID。京东 HTML 入口优先使用最近60秒捕获的对应 SKU 信息。缺少有效上下文时，按 URL 商品编号查询慢慢买历史摘要，从 HTML 包装清单读取说明；如摘要含当前到手价且配置了 API key，使用该第三方参考价调用 Jev，明确标记来源与账号价格未获取；建议强制为“信息不足”，不展示无走势支持的抬价概率，不写入本地账号价格记录。通知先显示 Jev 参考价分析，再展示历史价；没有参考价时提示未运行，请求失败时提示失败并仍展示历史价。同商品同参考价的成功分析不会重复调用，失败一分钟后可重试。历史摘要成功通知间隔10分钟，失败提示间隔1分钟，慢慢买配置变化可立即重试。每次历史接口最多2.5秒，历史链路总预算9.5秒，Jev 最多5秒，总保护15秒；全部退出路径 `$done({})`，请求和响应 body 都不修改。等待分析可能延迟商品响应。模拟验证已覆盖签名、历史链路、商品错配、缓存、配置隔离、通知顺序、失败与超时；仍需你手机上的京东/慢慢买实际响应及真实 Jev key 验证。第三方非公开稳定 API，无当前可用性承诺。若 MitM 影响商品页，关闭本引用及新增主机解密，不绕证书。

通知底部“结果说明”为根据决策与缺失字段生成的简短解释，不是 Jev 返回的自由文本。相同价格日期的历史项目合并展示。京东 mGetsByColor JSON/JSONP 按 SKU 缓存60秒，批量响应本身不通知；图文入口只使用对应商品的新鲜价格，并标明“京东展示价 · 券补贴未确认”，不冒充账号到手价。该接口在用户截图中已确认存在，但尚未验证能返回当前目标商品。

京东商品详情接口优先直接提取名称、价格和价格条件；允许 functionId 出现在任意查询参数位置，兼容根路径、/api、/client.action。仅匹配现有已配置接口名称，不把日志接口加入规则。新增 skuName 标题与嵌套 jdPrice.price 解析；出现多个商品编号时跳过，商品编号只用于身份校验与跨响应关联。该调整尚未证明用户当前京东版本会返回这些商品详情接口。
